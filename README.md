# knowledge-assembler

当用户提出需要解释、分析或解决的研究问题，并希望把多领域知识组装成完整文章时使用；也适用于在同一对话中切换论证路径。只改标题、润色已有稿件、查单项事实或生成摘要时通常不触发。

## 安装

```bash
npx -y skills add zhj022326-commits/knowledge-assembler -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $knowledge-assembler 研究这个问题，并将相关知识组装成一篇有解释力的文章。

## 运行依赖

- 支持 Agent Skills 的客户端
