# 自我叙事还原：失败模式

本文件以原始说明书和案例为判断依据。第一部分整理原文的禁止事项、错误示范与案例边界；第二部分记录本次开发、实际输出和验收中已经出现的偏差。辅助说明不能改变原文的推断尺度或输出要求。

## 原文规定的失败模式

| 失败模式 | 如何识别和纠正 |
| --- | --- |
| 把自述当作已证实的人格 | 撤销当事人给自己的标签，从行为、利益及叙事目的重新判断。 |
| 找到一个漏洞就结束 | 完整阅读，寻找统摄全文的共同机制。 |
| 为还原而制造问题 | 普通成绩、事实复盘、已明确且没有包装的私人利益，没有其他机制时终止。 |
| 攻击未知资源 | 全马三小时案例可以识别个人经验泛化，不能凭空认定身体天赋或经济优势。 |
| 为深入另造欲望 | 不从阶段业绩凭空推出晋升、权力或被委以重任等具体目标。 |
| 用模糊措辞保留无依据推断 | 舍弃无依据判断；有依据就直接还原，没有其他有效内容就终止。 |
| 无依据否定实际成绩 | 分析其索取的额外认可，不把成绩本身贬为伪装。 |
| 先肯定再转折 | 取消“我确实很努力，但是……”等铺垫，直接输出核心机制。 |
| 逐项结算功过 | 内部考虑全部事实，外部只提取有依据的欺骗、自欺、利益包装和叙事越权。 |
| 逐句改写成贬义词 | 整体归纳，不把输入当输出提纲。 |
| 把反驳和愤怒当心虚 | 判断证据实际影响，不把反应本身自动当作动机证据。 |
| 固守被推翻的判断 | 内部停止采用旧判断，仅输出新增材料中新的有效机制；没有则终止。 |
| 进入辩论或认错程序 | 不逐条质问、辩护或主动道歉；按追加证据规则处理。 |
| 把有限真实证据当全面证明 | 某证据真实不代表全部自我评价成立；可能隐瞒也不代表全部证据虚假。 |
| 用第二人称指责 | 实际结果统一用当事人第一人称。 |
| 固定套话或心理术语堆砌 | 使用简洁日常语言，不加层级标签、解释、免责声明或强制总结。 |
| 终止时正面认证 | 仅输出唯一终止语，不解释或肯定叙述真实性。 |

完整判断规则见 [完整规则](core-rules.md)，原始十组回归案例见 [测试案例](test-cases.md)。

## 已出现的理解、实现和验收偏差

| 已出现的问题 | 具体表现 | 原文依据与纠正方向 |
| --- | --- | --- |
| 入口弱化现实处境分析 | 摘要强调得失和利益，对能力、胆量、未展示事实的提醒不足。 | 第三节事实还原、第四节重建现实：同时考虑能力、资源、权力、胆量、被动处境和选择性披露；不据此编造未知事实。 |
| 把有限禁令扩大 | 把“不必要的事实复述”“不逐项改写经历”压缩为“不复述经历”。 | 第五、八节及案例 3、7：取消冗余与认可程序，保留直接支撑机制的具体行为。 |
| 第一人称分析腔 | 实际输出出现“把自己已经主动争取的回报从动机里抹掉”，以及“把……的利益诉求，说成……”。 | 第二、四、八节：压缩为自然、直接、日常化的第一人称；机制要表达清楚，不能只换代词。 |
| 正文重复套句 | 多组结果反复以“我把 A 当成 B，再把 C 说成 D”组织。 | 第二节第 10 条：不机械套用固定句式。原例也使用“我想把……”，所以不禁止该句式本身。 |
| 为修辞另造禁令 | 曾建议把直接欲望自白当主要标准，倾向于排斥抽象词和描述包装行为的句法。 | 原例 2、4 同时包含策略描述和“成功的解释权”。判断整段是否自然、有内容，不按词类或某个句式一律排除。 |
| 强化原话程度 | 案例 9 的“关键时候比较靠得住”被写为“关键时刻一贯靠得住”。 | 第七节及案例 9：可以指出阶段表现向稳定评价扩展，不能把较有限的自我评价改成更绝对的主张再攻击。 |
| 局部命中替代整体还原 | 案例 8 的执行指出了复制条件，却没有充分覆盖原例的普通人逆袭榜样诉求。 | 第三、四节及案例 8：结合全文判断条件伪装、经验泛化和叙事目的；不要求每次罗列所有机制，也不能以找中一点代替整体理解。 |
| 只认机制命中便判通过 | 旧记录主要检查有没有新增天赋、资金、晋升等目标，对表达及还原完整度检查不足。 | 第十二节最终验收：机制、依据、整体归纳及简洁人话都需检查，分项记录缺口。 |
| 从终止语推定内部纠错完成 | 反驳后输出终止语，被用于宽泛肯定内部证据更新。 | 第六、九节：可观察的是未辩护、未重复旧判断、使用正确终止语；不能据此宣称已经验证全部内部判断。 |

表达理解参照 [原例的表达说明](expression-examples.md)。
