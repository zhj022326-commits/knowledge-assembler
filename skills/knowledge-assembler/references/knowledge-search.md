# 知识搜索

## 目标

围绕已经确认的研究命题发现能解释、分析或解决问题的知识，为文章组装提供机制、证据和竞争解释。搜索目标是扩大有效知识发现，不是尽快找出支持预设结论的材料。

## 搜索流程

### 1. 转译问题

将命题拆为现象、研究对象、关键变量、关系和待解释结果。列出不同学科中的对应术语、机制名称和可检索表达，不受用户原始措辞限制。

### 2. 建立有区别的搜索方向

按机制或研究视角划分方向，例如：

- 直接因果机制与中间变量；
- 行为、认知、组织、制度或技术层面的解释；
- 前因、后果、适用条件和反例；
- 历史案例、实证研究、理论模型和实践方法；
- 与当前主解释相竞争的独立归因。

方向之间要有实质区别，不只更换关键词。

### 3. 递归扩展与跨学科映射

每次发现有解释价值的知识，检查其前因、后果、运行条件、相关机制和应用场景。寻找其他学科中具有相似变量关系或因果结构的知识。跨学科映射必须说明机制相似之处，不能只凭术语相似。

### 4. 搜索缺口与竞争解释

检查当前解释尚未覆盖的现象、独立归因、缺失条件和反例；围绕会改变结论的重要缺口继续搜索。搜索阶段保留冲突材料，不强行调和。

### 5. 深挖重要知识

对核心理论、模型或研究进一步查明：关键变量、作用过程、适用条件、依据类型、主要限制和与研究命题的关系。只记录名称和概述不足以支撑后续文章。

## 来源处理

- 有搜索工具时，使用不同检索表达；涉及关键理论和事实时尽量追踪原始资料或权威来源。
- 将实证结论与模型推导分开。来源无法确认时，不补猜作者、年份、页码或结论。
- 没有联网能力时使用已有知识，但不得声称进行了实际搜索；对未核实的来源和时效性作清楚说明。
- 用户材料可作为搜索线索和待检验观点，不自动视为已证实事实。

## 停止判断

不规定固定搜索轮次、理论数量或学科数量。继续搜索，直到下一轮搜索不太可能改变主解释、关键机制、重要条件或主要争点；若发现新的独立机制、重要反例或影响结论的缺口，则继续。避免重复搜索已经充分覆盖的方向。

这一停止规则借鉴信息觅食的收益判断：比较新增信息的预期价值与继续搜索的成本。它是效率启发式，不能证明搜索完整，也不能替代来源核实。

## 阶段产出

将重要发现整理为 references/knowledge-handoff.md 定义的材料包。搜索不直接写成面向用户的摘要或文章。
