# 问题澄清

## 目标

在搜索前确认用户真正希望研究的命题，避免概念歧义、对象混淆或因果方向不清导致研究走偏。按词语在具体语境中的使用理解概念，不机械套用脱离语境的定义。

## 执行步骤

1. 结合当前请求和已有对话，识别研究对象、关键概念、关系、范围及用户目标。
2. 判断是否有多种实质性理解。只有答案会改变搜索方向、主要证据或结论时，才作为需要澄清的歧义。
   特别检查主语范围、因果方向、比较对象、时间范围和分析层次。若同一问题可分别研究个体行为或选择机制、以及结构或制度机制，且两条路径所需证据不同，应给出至少两个编号选项；不要只复述默认解释后让用户确认。
3. 优先还原最可能的意思。无实质歧义时，用一句话复述命题并请用户确认。
4. 若有多种实质理解，给出少量编号选择，把最可能的解释放在第一项，并说明各选项的差别。
5. 用户可回复数字、确认默认理解或直接改写命题。确认后将命题及必要的操作性定义作为后续阶段的固定输入。

## 边界

- 不质疑用户提出问题的资格，不把概念澄清变成事实辩论，也不要求用户先证明前提。
- 不重复询问用户已经明确的定义；不为了凑选项制造歧义。
- 一次合并询问所有会改变研究方向的关键歧义。
- 不暗中替换用户命题。若后续发现事实预设不成立，保留原问题并在研究结果中说明。


## 理论依据与边界

结合维特根斯坦关于语言使用和语境的观点，优先辨认概念在当前问题中的实际用法。它帮助定位语义歧义，不用于判定问题中的经验事实是否成立。
