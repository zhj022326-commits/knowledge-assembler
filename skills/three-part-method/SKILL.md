# 三分法｜文章战队检查与改写

只判断和修正作者与目标观众的战队关系。

核心关系：

> 作者 + 目标观众 → 第三对象

判断重点不是句子是否尖锐，而是目标观众认同作者观点时，是否必须先接受作者对自己的否定。

## 不变量

1. 先识别目标观众，再判断战队关系。
2. 批评其他人群、某种行为或负面品质，不自动构成战队问题。
3. 只展示有明显战队问题的句子，不为了完成格式强行报错。
4. 尽量保留原文的观点、事实判断、结构、攻击力、情绪强度和语言习惯。
5. 只调整战队关系，不顺手优化逻辑、修辞、节奏、开头、事实或传播效果。
6. 不强制每句话出现第三对象，不凭空制造敌人、事实或原文没有的主张。

需要确认三分法的完整定义、切割边界或五种调整方法时，读取 [references/三分法教案.md](references/三分法教案.md)。教案用于理解和选择方法，不把其中全部选题分析步骤机械执行一遍。

## 识别处理模式

根据用户的自然语言自动选择模式，不要求填写表单。

### 文章检查

用户输入一句话、一段文案或一篇文章，且没有明确要求直接重写全文时，默认执行文章检查。

### 局部改写

用户指定某句话、某一段，或针对上一轮结果回复“改用 A”“再改一下”“保留攻击力”等要求时，只修改对应内容。连续修改时沿用已经确认的目标观众、观点和限制，除非用户改变它们。

### 全文改写

只有用户明确提出“全文改写”“直接改完整篇”等要求时，才输出完整文章。没有问题的部分尽量保持原样。

## 工作流程

### 1. 识别目标观众

- 用户明确说明目标观众时，直接采用。
- 用户没有说明时，根据主题、称呼、处境、利益、承诺和上下文推断主要争取的人。
- 不把所有可能看到文章的人都当作目标观众。
- 只有存在会实质改变判断或改写方向的重要歧义时，才用一句话询问目标观众；其余情况直接完成，并把推断简短标明。

### 2. 逐句检查内部对立

结合上下文判断每个句子，重点检查：

- 句子是否直接把目标观众描述为低劣、愚蠢、懒惰、失败、不配或应受训斥的人。
- 句子是否用具体身份、收入、经历、行为或其他条件，把大量目标观众强制装进攻击对象。
- 作者是否利用目标观众的错误来证明自己更清醒、更高级。
- 开头虽然与观众结盟，正文是否又开始处理、教育或羞辱目标观众本人。
- 目标观众要站到作者一侧，是否必须先承认作者正在否定自己。

以下情况本身不算问题：

- 作者批评目标观众之外的人群，而目标观众可以自然站在作者一侧。
- 作者批评一种行为、机制、方法、作品、规则或问题，目标观众不必把批评等同于对自身人格的否定。
- 作者使用强烈措辞，但攻击对象与目标观众已有清楚边界。
- 目标观众能够通过认同作者的判断，与被批评的负面品质自然分离；具体条件没有把他们强制归入敌方。

### 3. 选择最小改动

只对确认存在问题的表达，按需要选择一种或组合少量方法：

- 深入区分：增加必要条件，缩小攻击范围，让主要观众能与批评对象分离。
- 还原问题：把对人的定性转回观众想完成的目标，以及当前方法为何没有产生预期结果。
- 改变攻击点：保留强判断，把攻击转移到合适的人群、机制、方法、话术或其他对象。
- 从批评改成分享：用发现、解释或新视角解除教训关系，同时保留原文的判断力度。
- 调整选题：只有原题无法在不改变核心目标的情况下修复时，才提出新的角度；不要擅自改变原文主张。

第三对象可以是人群，也可以是行为、问题、机制、方法、作品、规则、案例或其他具体对象。修改到目标观众能自然站在作者一侧即可停止。

### 4. 检查改写结果

确认改写后：

- 核心观点和事实判断没有被改变。
- 攻击力、立场、情绪强度和原有风格没有被无故软化。
- 没有凭空补充敌人、事实、动机或价值判断。
- 必要上下文没有再次把目标观众推回对立面。
- 没有借机修改战队关系之外的内容。

## 输出规则

### 文章检查

先用一行标明明确或推断的目标观众：

```text
目标观众：……
```

然后只列存在明显问题的句子，每条使用：

```text
原句：……

问题：简短说明该句怎样破坏作者与目标观众的联盟关系。

改写 A：……

改写 B：……
```

两种改写都应可直接使用，并尽量提供不同的关系调整方式。如果一种改法明显更合适，只提供一个改写，不凑数。

没有发现明显战队问题时，直接回答：

```text
目标观众：……

未发现明显战队问题，无须修改。
```

不要附加文章评分、优缺点总结或其他写作建议。

### 局部改写

直接给出修改后的句子或段落。只有用户需要理解差异时，补充一句与战队关系有关的说明，不扩展到其他写作问题。

### 全文改写

输出完整可使用的文章。保留原文结构和无问题内容，只修改有战队问题的句子及维持上下文所必需的部分。输出前逐段检查是否出现新的内部对立。

## 停止条件

- 已完成当前模式要求的检查或改写。
- 全文没有明显战队问题，明确告知无须修改。
- 缺少目标观众信息且不同判断会导致相反结论，用一句话询问后停止，等待用户回答。
- 用户要求的是本 Skill 边界之外的任务，简短说明本次只处理战队关系，不执行未经要求的全面创作或评价。
