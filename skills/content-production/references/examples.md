# 模式示例

示例用于说明任务边界与输出粒度，不是固定模板。不要照搬示例中的候选。

## 模式1 开口评估

### 正常示例

输入：为什么有些人吵架非要逼你认错？

输出：

```text
开口强度：7/10。简评：场景熟悉，冲突明确；可以让观众更快看到争吵双方在争什么。

默认 A：
1. 有些争吵明明已经解释清楚了，为什么还是非要你亲口认错？
2. 一句道歉说完了，对方却要求你再说一遍，他到底在确认什么？
3. 为什么有些争吵到最后，讨论的已经不是事情本身，而是谁有资格判定对错？

创意 A：
4. 假如两个小孩争一块饼干，家长只要求其中一个道歉，另一个会怎么理解这次争吵？
5. 如果一场比赛必须由球员先承认犯规，裁判才宣布判罚，大家还会相信这个结果吗？

回复编号可继续修改；回复0可换一组。
```

### 常见失败

输入同上，失败输出：

```text
为什么他逼你认错？为什么他非要你认错？为什么他要你道歉？……
```

这类输出只是改写句式，缺少强度判断，也没有形成 3 个默认 A 与 2 个创意 A。

## 模式2 理论检索

### 正常示例

输入：为什么有些人越老实越容易吃亏？

输出：

```text
1. 退出选择与议价能力｜聚焦：可替代选项越少，拒绝不利条件的能力通常越弱。关联：可以解释某些关系中缺乏退出选择的一方为何更容易被要求让步。
2. 重复互动中的行为预期｜聚焦：过去可观察的让步行为会影响别人对未来行动的判断。关联：可以分析反复接受不合理要求如何改变关系中的策略预期。
3. 边界与合作条件｜聚焦：合作能否持续，取决于各方的行为边界及违反边界的后果。关联：可以解释为什么单方面持续退让未必换来对等合作。
```

本例沿用设计材料中的示例，只演示候选的表达粒度。真实任务通常给约 5—8 项；候选不足时可以少给。

### 常见失败

输入同上，失败输出：

```text
这涉及心理学、社会学和博弈论。下面给你写一篇文章提纲，再设计情绪钩子……
```

这类输出只有学科标签，没有具体判断，还越界写了提纲和传播方案。

## 模式3 观点找开口

### 正常示例

输入：退出权决定议价能力，找开口。

输出：

```text
默认 A：
1. 为什么有些员工能力很强，老板却一点也不怕他辞职？
2. 为什么有些人在感情里越肯退让，反而越难得到尊重？
3. 同样是谈价格，为什么有的人开口就能要到更高的价钱？

创意 A：
4. 假如你明天突然中了一个亿，再去公司上班，你和老板说话的方式会发生什么变化？
5. 假设一座孤岛只有一家商店，商店老板为什么可以把一瓶水卖得比外面贵得多？
```

### 常见失败

输入同上，失败输出：

```text
退出权为什么重要？为什么退出权会影响议价？退出权对谈判有什么影响？……
```

这类输出反复换问法，没有形成五种观看入口；后接长篇理论解释也超出了默认交付。
