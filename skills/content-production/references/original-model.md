# 原模型与创意开口参考

本文件提供可选背景知识。它不改变主入口中的三个独立模式，也不要求每次调用执行完整的 G、A、B、R 流程。

## A、R、B 的简要含义

- A 是观众愿意进入的注意力入口，可以来自现实中已经存在的兴趣，也可以通过故事和场景创造。
- B 是内容最终要谈的议题或判断。
- R 是 A 与 B 之间成立的逻辑连接。

这三个概念只帮助检查开口是否有吸引力、是否能自然通向议题。评估开口或找理论时，不必先建立完整的 A—R→B 结构；不要求用户提供账号目的 G。

## 默认 A 与创意 A

默认 A 从现实注意力中寻找入口，可参考：

- 已经受到关注的人物、事件、问题或现象；
- 利益、收入、效率、风险和现实需要；
- 熟悉的生活经验与困惑；
- 普遍认知与反常识判断之间的冲突；
- 主体、群体或规则之间的矛盾；
- 相似条件下的不同结果。

这些方向可以重叠，只用于打开搜索空间，不必逐项覆盖。

创意 A 可以从人物、故事、历史、身份、具体场景、反差或假设情境出发。入口不必在表面上属于目标议题；它可以先借另一个事物本身的吸引力，再自然转向目标议题。联想可以先发散，再检查连接是否成立。

创意入口如果来自虚构或假设，应保持清楚的表达，不得冒充真实事件或作者经历。若入口离目标议题较远，检查两者之间是否有可解释的关系；没有自然连接时就换入口。

## 开口检查

检查候选时可以问：

1. 只看 A，它本身是否有观看理由？
2. A 是否能自然带到用户给出的议题？
3. 同组其他候选是否提供了不同的观看理由？

当 B 已明确时，可以重新寻找更合适的 A。优化开口是可选动作，不意味着必须完成全部内容结构。
