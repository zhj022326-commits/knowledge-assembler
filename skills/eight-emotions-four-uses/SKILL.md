# 八情四用

用情绪修辞改变观众判断问题的方式，使同一个观点产生不同传播效果。情绪是工具，不是目的。

## 理论依据

每次执行前完整阅读 [references/八情四用教案.md](references/八情四用教案.md)。以该教案为八种情绪的定义、四种用途、作用机制和判断转换的唯一理论依据。

- `SKILL.md` 决定如何执行任务；教案决定依据什么执行。
- 不增加新的情绪类型，不用通用情绪写作理论替换本模型，不擅自重释原作者理论。
- 不把情绪理解为提高音量、堆叠攻击性词汇或单纯感染观众。必须先转换判断问题，再形成表达。

## 自动识别任务

根据用户当前请求只执行以下一种功能：

1. **情绪角度生成**：用户直接给出观点、命题、选题、句子或简短描述，且没有要求检查、优化或指定情绪时，执行默认功能。
2. **文案诊断与改写**：用户给出已写好的句子、开头或完整文案，并要求检查、优化、增强或修改时执行。
3. **指定情绪转换**：用户明确指定一种或多种情绪，或指定提高价值、推动改变、建立等级、建立立场中的一种传播目的时执行。只做指定转换，不额外调用其他功能。

意图不明确时优先执行情绪角度生成，不反复询问。用户明确的数量、语气、尖锐程度、句式保留和使用位置要求优先于默认设置。

## 共同执行机制

在内部依次完成：

1. **观点理解**：用一句话锁定原命题真正主张什么，区分观点与例子，不改动其基本含义。
2. **传播目的判断**：判断更适合提高价值、推动改变、建立等级或建立立场中的哪些目的。
3. **情绪选择**：从对应情绪组选择最能服务目的的情绪；不平均分配，也不为了覆盖八种而硬套。
4. **判断问题转换**：明确观众原本在判断什么，再用所选情绪把判断问题换成教案规定的方向。
5. **修辞表达**：把新的判断问题写成自然、有冲突或反差、具有传播价值的表达。

第 4 步是质量核心。若表达只换了强烈词语、没有改变观众的判断问题，重新生成。

除非用户要求解释，不展示上述内部过程，只给结果。

## 功能一 情绪角度生成

默认生成 5 条：

- 第 1—3 条选择最适合当前观点的情绪方向。
- 第 4—5 条尝试其他可成立的情绪方向，扩大表达可能。
- 不要求覆盖全部八种情绪。同一种情绪可以出现多次，但每次必须改变利益、损失、身份比较、责任关系或其他判断角度，不能只换词。
- 可以挖掘原命题隐含的利益、损失、身份、比较、责任、归因与保护关系，但不得改变原命题，不得凭空编造人物、数据、经历或事件。
- 避免机械套用固定句式。恐惧不必总用“最可怕的不是”，鄙夷不必总用“真正厉害的人”。

输出格式：

```text
1. 【情绪｜传播目的】参考表达
2. 【情绪｜传播目的】参考表达
3. 【情绪｜传播目的】参考表达
4. 【情绪｜传播目的】参考表达
5. 【情绪｜传播目的】参考表达

回复 1—5：沿对应方向再生成 5 个版本；回复 0：重新寻找 5 个角度。也可以直接说明要更尖锐、更克制、保留原句式或指定使用位置。
```

不要在结果前增加长篇分析、理论介绍或泛泛评价。

## 功能二 文案诊断与改写

1. 识别原文正在使用的主要情绪修辞，以及它实际服务的传播目的。
2. 只选择通过情绪修辞能产生明显价值的句子；原句已经足够好时不强行修改。
3. 对每个位置给出原句、具体问题和可直接替换的改写参考。问题说明聚焦判断转换是否缺失、情绪与目的是否错位、力度是否不足或表达是否机械。
4. 可用不同情绪重新表达，但必须保持原意。
5. 不主动检查文章结构、论证逻辑、语法规范、标题、拍摄或营销方案。
6. 不主动重写整篇文章。只有用户明确要求全文改写时才提供全文版本。

默认输出格式：

```text
当前主要修辞：【情绪｜传播目的】一句话说明其作用。

1. 原句：……
   问题：……
   改写：……
```

如果没有值得修改的位置，直接说明原文的情绪修辞已经成立，并指出成立在哪里；不要为了完成格式制造问题。

## 功能三 指定情绪转换

- 用户指定情绪时，直接使用对应判断转换机制，默认提供 3 条不同角度的参考。
- 用户指定多种情绪时，按指定情绪分别表达；除非用户另有数量要求，每种提供 3 条。
- 用户只指定传播目的时，从该目的对应的两种情绪中选择，可单独使用一种或组合使用，以更适合原观点为准。
- 用户明确指定数量时严格遵守。
- 不附带诊断、其他情绪建议或完整创作扩展。

每条仍使用 `【情绪｜传播目的】` 标注，便于用户继续选择。

## 连续交互

在当前对话中保留：原观点、最近一轮结果、用户选择的编号、指定情绪或传播目的，以及用户锁定的句式和力度。

- 用户回复 `1`—`5`：沿对应条目的判断角度再生成 5 个新版本，不要求重发原文；用户另有数量要求时按用户要求。
- 用户回复 `0`：回到原观点，重新寻找 5 个不同角度；优先避开已经生成过的判断路径和句式。
- 用户用自然语言继续时，直接执行，如“第 3 条再来 5 个”“全部改成恐惧”“保留我原来的句式”“改成正文表达”。
- 若当前对话没有可对应的上一轮结果，才请用户补充观点或文案。

## 执行纪律

- **理论忠实**：教案优先。八种情绪及四种用途不得错配。
- **传播效果优先**：优先寻找冲突、反差、利益关系、身份判断、相似者比较、责任归属和保护对象；不为显得理性而默认削弱修辞强度。
- **观点一致**：可以挖掘隐含前提，不能为了情绪效果反转或替换用户观点。
- **事实克制**：具体事实必须来自用户提供的内容；没有依据时使用一般性表达，不虚构细节。
- **角度真实不同**：区别应来自判断问题、利益关系或身份位置的变化，而不是同义词替换。
- **输出简约**：默认直接交付可用表达，不讲课，不展示复杂分析。
- **范围克制**：不主动生成文章大纲、完整脚本、理论论证、营销方案、拍摄指导、传播评分、用户画像或多 Skill 工作流。

## 交付前自检

只在内部检查：

1. 至少 3 条是否具有明显不同的判断角度。
2. 每条是否真正改变判断问题，而非只增加攻击性词汇。
3. 情绪与传播目的是否符合教案。
4. 是否保留原命题且没有编造事实。
5. 是否避免重复句式并保持简洁、可直接使用。

发现问题时只重写有问题的条目，不向用户展示评分过程。
