# 知识整理规则

## 目标

把可用逐字稿整理成方便教学的材料，同时保持作者原意、信息边界和知识密度。原始逐字稿必须单独保留。

## 可以做

- 修正确有把握的错别字、同音字、明显术语误识别和断句。
- 删除无实际意义的口头禅、机械重复、卡顿和转写噪声。
- 识别并组织核心命题、知识点、论据、案例、操作方法、前提和限制。
- 将零散但有明确逻辑关系的内容放在一起，同时保留作者的推理顺序。
- 把画面文字救稿与语音稿合并，但标明来源和不确定处。

## 不可以做

- 不主动搜索外部资料来“补全”视频。
- 不加入作者没提出的理论、案例、论据、结论或章节。
- 不用模型熟悉的标准框架替换作者自己的表达和推理。
- 不把含保留条件的观点改成确定结论。
- 不为延长教学而制造问题、练习或应用场景。
- 不把无法确认的术语静默改成猜测结果。

## 建议输出

根据实际内容取舍，空栏目不要硬凑：

```markdown
# 视频学习材料

## 来源与文字来源
- 视频：...
- 文字来源：平台字幕 / 语音识别 / 画面文字救稿
- 待核处：...

## 核心命题
...

## 知识结构
### 知识点或步骤一
- 要点：...
- 作者依据/案例：...
- 条件或限制：...

## 作者的结论或方法
...

## 整理说明
- 删除了哪些类型的口语冗余
- 哪些词句仍不确定
```

材料很浅时，一个核心命题和几个要点就够；材料丰富时才拆出更多层级。不要为了套模板制造内容。
